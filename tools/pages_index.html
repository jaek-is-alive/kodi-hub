📺 Jacob's Hub

Personal Kodi repository — one launcher over Umbrella, The Loop & CocoScrapers.

Install (first time):

  1. On the Kodi device, download the repository zip:
    ⬇ repository.jacobshub-1.0.0.zip
  2. Kodi → Add-ons → Install from zip file → pick the downloaded zip.
  3. Add-ons → Install from repository → Jacob's Hub Repository → Video add-ons → Jacob's Hub.

After that, updates are automatic — Kodi pulls new versions from this site silently. (No need to add this URL as a "file source"; GitHub Pages doesn't list directories, so just use the zip above.)

Prereqs, installed from their own repos: Umbrella, CocoScrapers, The Loop. Source: github.com/jaek-is-alive/kodi-hub.
