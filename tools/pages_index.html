📺 Jacob's Hub

Personal Kodi repository — one launcher over Umbrella, The Loop & CocoScrapers.

Short repo URL:

jaek-is-alive.github.io/kodi-hub/

Option A — Add as a source (Firestick friendly)

  1. Kodi → Settings → File manager → Add source → enter https://jaek-is-alive.github.io/kodi-hub/ → name it hub.
  2. Add-ons → Install from zip file → hub → pick hub.zip.
  3. Add-ons → Install from repository → Jacob's Hub Repository → Video add-ons → Jacob's Hub.

Option B — Downloader app / direct file

If Option A doesn't list the zip, grab the file directly:

⬇ hub.zip

URL: https://jaek-is-alive.github.io/kodi-hub/hub.zip — paste into the Downloader app, then Kodi → Install from zip file → your Downloads folder → hub.zip.

After install

Open Jacob's Hub → Tools & Setup → ⚙ Setup to install Umbrella, CocoScrapers & The Loop, then say yes to wiring CocoScrapers into Umbrella. Updates are automatic after that.

Prereqs are handled by Setup. Source: github.com/jaek-is-alive/kodi-hub.
